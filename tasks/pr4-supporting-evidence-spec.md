# PR 4 draft specification: supporting measurements and mappings

Depends on merged/published PR 3, closes #737 and provides the native contract for dependent external-source PR #746; targets next patch release.

## Exact source inventory

Input is one verified PR 3 package, not separately named sidecar paths. It already embeds the v4 native `bulk_proteomics.parquet` (2,269,288), `line_expression.parquet` (42,909), `peptide_mappings.parquet` (6,205,013), and mapping metadata. Add a pinned `source_assets/` namespace for bundled bulk CSV.gz and YAML metadata, expression CSV.gz and source/anchor YAML, with content hashes and license/access provenance. Do not treat mapping rows, source rows, fractions, or derived transforms as independent biological specimens. The v4 corpus only contains two bulk source populations and two expression profiles; PXD057588 and the other quantitative acceptance cases belong to the dependent source-generation PR #746. They must not be inferred from the v4 cells.

Bulk grains: 2,047,003 Bekker-Jensen peptide detection rows with `n_replicates_detected` and no quantitative intensity, 156,211 Bekker-Jensen protein rows with `log2_intensity`, 66,074 CCLE protein rows with `abundance_log2_normalized`. Retain raw `abundance_percentile` as a derived, source-scoped rank, not a common abundance scale. Proteins and peptides keep distinct result IDs and result kinds. Record source row index, source/method context and protocol evidence on every typed result. Source sample labels are labels; no exact material, specimen, donor, aliquot, or acquisition identity is established. `n_fractions_in_run` and `n_replicates_detected` are count units, not extra results. The native table has 19 observed `(source, grain, enzyme, fraction-count, enrichment)` combinations, including TiO2 arms; report each scope and do not pool enrichment or fractionation by default. Search enzyme semantics must use source `search_enzyme`/MaxQuant specification when available: the legacy Trypsin/P display string states an incorrect cleavage exception per the bundled source note; preserve it raw and do not derive cleavage features from it.

Expression grain: 23,716 ENCODE GM12878 gene TPM rows and 19,193 DepMap HAP1 gene rows with log2(TPM+1) normalization. `tpm` and `log2_tpm` are two representations on one result, not independent biological measurements. ENCODE reports TPM and derives log2(TPM+1); DepMap reports log2(TPM+1) and derives TPM by inversion. Record which representation was source-reported, the transform and denominator/subset notes; do not imply ENCODE TPM and DepMap relative values share a calibrated scale. `transcript_id` is unpopulated on all 42,909 v4 rows, so transcript measurements remain a contract with zero materialized observations. Retain profile/backend, gene naming, source/normalization, species/license and line/parent-line keys. Line anchor tiers remain typed relations with source-backed registry versions; even tier-1 exact-line RNA is only same-line evidence, not a paired specimen.

Mapping grain: 6,205,013 source peptide/protein-position records for 1,145,721 mapped unique peptides, human Ensembl 112. The corrected-corpus audit has 1,506,664 eligible peptide input sequences after excluding non-peptide-ligand rows. The three native partitions have 1,506,973 nonempty strings, including 313 unique strings on flagged rows (four also occur on eligible rows). Explicitly count and retain unmapped inputs without inventing relationship rows. One mapping ID per native row index; preserve duplicate-looking alternative occurrences and all eleven source fields, including gene/transcript, canonical proxy, position/flanks/proteome provenance. No deduplication into one protein per peptide, and no extra assay rows.

## Physical typed relations

- `typed/bulk_results.parquet`: one row per native bulk row, with stable result ID, native row index, source population, grain, source sample label, peptide/protein key, protocol/arm descriptors, detection scope and identity uncertainty. Required fields vary by peptide detection versus protein abundance, and source-specific quantity scale.
- `typed/bulk_measurements.parquet`: peptide detection status/replicate count as a scoped endpoint; protein abundance as source-specific log2 LFQ or CCLE relative log2 normalization; percentile as a source-derived annotation. Raw numeric values, null state and units remain distinct. One result may have multiple representations without multiplying source result count.
- `typed/expression_results.parquet` and `typed/expression_measurements.parquet`: one native gene result per row with source profile and source-specific normalization, TPM and log2(TPM+1) as two documented representations on the same result.
- `typed/peptide_protein_occurrences.parquet`: all mapping alternatives, source row index, proteome/source, position/flanks and exact peptide sequence.
- `typed/source_protocols.parquet` and `typed/line_anchors.parquet`: source study defaults and actual per-row protocol dimensions distinct; registry anchors and relation precision. No inferred exact material link. Keep native source YAML and rows.

## Semantics and audit

One atomic package successor to PR 3, embedding its manifest and all files. Export a complete source-field disposition, typed relation registry, required fields by evidence family, manifest hash inventory and source revision pins. Validate no loss: source row count, source fields/values and hashes, typed result IDs one-to-one, mapping row count one-to-one, measurement/representation counts, null/blank distinction, enzymes/normalizations. Any new source key requires explicit review.

Offline fixtures: four enzyme queries do not mix protease scopes; no fabricated peptide intensity or negative detection; source-specific protein quantity scales; expression profile and normalization; zero v4 transcript observations; ambiguous peptide mapping remains many-to-many; same-line/parent-line surrogate cannot satisfy `exact_material`; technical fractions/replicate counts do not inflate biological observations; malformed source/hash/key fails atomically. Independent full-source replay and final-head CI. Bump version, format/lint/test, review, merge and release before PR 5.

## Contract handed to external quantitative source PR #746

Native v4 cannot satisfy these claims; defer training admission until the source generation and acceptance fixtures are implemented.
