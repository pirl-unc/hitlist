===== hitlist --help =====
usage: hitlist [-h] [--version]
               {data,build,evidence,report,export,audit-splits,verify-evidence-bundle,reassign-alleles,qc,pmhc,samples,proteomics,expression}
               ...

hitlist: verified immune and nonimmune evidence for model training

positional arguments:
  {data,build,evidence,report,export,audit-splits,verify-evidence-bundle,reassign-alleles,qc,pmhc,samples,proteomics,expression}
    data                Manage external datasets
    build               Build canonical artifacts: observations.parquet (from IEDB/CEDAR), cached
                        scan index, reference proteomes.
    evidence            Query a verified multi-modality evidence package
    report              Data quality report. Reads observations.parquet by default (instant); pass
                        --from-csv to fall back to a live raw-CSV scan.
    export              Export curated study metadata as CSV
    audit-splits        Audit partitions supplied as verified training bundles
    verify-evidence-bundle
                        Verify hashes and scientific relationships in an evidence bundle
    reassign-alleles    Reassign class-only peptides (mhc_restriction='HLA class I') to their
                        best-scoring allele via MHCflurry / NetMHCpan
    qc                  Audit corpus + curation: allele-resolution histogram, normalization drift
                        in pmid_overrides, YAML/data allele cross-reference.
    pmhc                Per-protein x allele pMHC evidence: MS-attested peptides grouped by (gene,
                        allele), with optional NetMHCpan/MHCflurry scoring.
    samples             Per-sample MS conditions table (cell line, donor, instrument,
                        perturbation, etc.). Replaces `export samples`.
    proteomics          Bulk (non-MHC) proteomics index: shotgun MS peptides + protein abundances
                        from CCLE and Bekker-Jensen 2017. Replaces `export bulk-proteomics`.
    expression          Per-line RNA / transcript TPM with provenance. Replaces `export line-
                        expression`.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

===== hitlist pmhc --help =====
usage: hitlist pmhc [-h] [--protein PROTEIN [PROTEIN ...]]
                    [--mhc-allele MHC_ALLELE [MHC_ALLELE ...]] [--sample NAME:ALLELE[,ALLELE,...]]
                    [--samples PATH.tsv] [--species SPECIES] [--source-species SOURCE_SPECIES]
                    [--host-species HOST_SPECIES]
                    [--source-context {activated_apc,adjacent,cancer,cell_line,ebv_lcl,ex_vivo,healthy}]
                    [--list-source-contexts] [--by-tissue] [--show-zeros] [--by-gene]
                    [--gene-set GENE_SET] [--list-gene-sets] [--expand-lines] [--expand-tissues]
                    [--predictor {mhcflurry,netmhcpan}] [--min-binder-class {strong,medium,weak}]
                    [--min-references N] [--min-samples N] [--cell-type TYPE]
                    [--format {table,csv,json}] [--output OUTPUT]

Per-protein x allele pMHC evidence query. Both --protein and --mhc-allele are optional; pass
neither to scan the whole corpus, just one to fix that axis. Pass --predictor
{mhcflurry,netmhcpan} to add binding-affinity scoring.

options:
  -h, --help            show this help message and exit
  --protein PROTEIN [PROTEIN ...], --gene PROTEIN [PROTEIN ...]
                        One or more proteins: HGNC symbol, Ensembl ENSG, or alias. Omit to scan
                        all genes.
  --mhc-allele MHC_ALLELE [MHC_ALLELE ...], --mhc-alleles MHC_ALLELE [MHC_ALLELE ...]
                        One or more 4-digit MHC alleles (HLA-A*02:01, HLA-B*07:02, ...). Space-
                        separated, comma-separated, or repeated -- a whole pasted genotype string
                        works as one argument, e.g. --mhc-allele "HLA-A*02:01 HLA-B*07:02" or
                        --mhc-allele HLA-A*02:01,HLA-B*07:02. Omit to scan all alleles. Mutually
                        exclusive with --sample / --samples — use those when each sample has its
                        own allele set instead of a cross-product across all of them.
  --sample NAME:ALLELE[,ALLELE,...]
                        Per-sample paired (name, allele set). Repeatable; alleles are comma-
                        separated after the colon. Example: --sample
                        patient1:HLA-A*02:01,HLA-A*24:02 --sample
                        patient2:HLA-A*01:01,HLA-A*24:02. Each sample is queried independently
                        against the protein list — results are sectioned by sample in the output.
  --samples PATH.tsv    Batch form of --sample: path to a TSV with one row per sample, two columns
                        'name' and 'alleles' (alleles comma-separated). Header row optional.
                        Mutually exclusive with --mhc-allele.
  --species SPECIES, --mhc-species SPECIES
                        Filter by MHC species (the species of the HLA/MHC molecule, e.g. 'human' /
                        'Homo sapiens'). Without it, results include every species the peptides
                        were observed on, sectioned with human first. The three species axes are
                        independent — see --source-species / --host-species.
  --source-species SOURCE_SPECIES
                        Filter by SOURCE species — the organism whose proteome the peptide comes
                        from (e.g. 'human' drops a SARS-CoV-2 viral epitope even though its MHC
                        and host cell are human).
  --host-species HOST_SPECIES
                        Filter by HOST species — the organism of the cell the peptide was
                        expressed/eluted in (e.g. a human gene presented in a mouse line).
  --source-context {activated_apc,adjacent,cancer,cell_line,ebv_lcl,ex_vivo,healthy}
                        Keep only observations from this curated source context: healthy, cancer,
                        cell_line, ebv_lcl, adjacent, activated_apc, ex_vivo. Run --list-source-
                        contexts to see what each means.
  --list-source-contexts
                        Print the available --source-context values (with descriptions) and exit.
  --by-tissue           Summarize WHERE the gene's peptides come from, in four sections: healthy
                        tissues / cancer tissues (by source tissue) and cancer / non-cancer cell
                        lines (by cell line). Each section shows observations, unique peptides,
                        references; sorted by observations. Combine with --source-context and
                        --species. Ignores --mhc-allele / --sample / --predictor.
  --show-zeros          With --by-tissue, show empty sections (as '(none)') instead of eliding
                        them.
  --by-gene             Per-GENE rollup: one row per gene with n_observations / n_unique_peptides
                        / n_references / n_samples, sorted by observations. Pair with --gene-set
                        CTA (or --gene) to summarize a panel. Honors --source-context and
                        --species; ignores --mhc-allele / --predictor.
  --gene-set GENE_SET   Expand a named gene set into the --gene filter (e.g. 'CTA' for the cancer-
                        testis-antigen panel). See --list-gene-sets.
  --list-gene-sets      Print the available --gene-set names (with descriptions) and exit.
  --expand-lines        With --by-tissue, group the cell-line sections by individual line name
                        (THP-1, HeLa, ...) instead of the default cell TYPE of origin (Monocyte,
                        Melanocyte, B cell, ..., EBV-LCL).
  --expand-tissues      With --by-tissue, split anatomical roll-up groups into their specific
                        organs (GI tract -> Esophagus/Stomach/Colon/...; CNS ->
                        Brain/Cerebellum/Spinal Cord). Rows a study labelled only with the
                        umbrella term show as '<group> (region unspecified)'. Default rolls them
                        up.
  --predictor {mhcflurry,netmhcpan}
                        Optional binding-affinity predictor. If omitted, only MS evidence is
                        reported (no affinity column).
  --min-binder-class {strong,medium,weak}
                        Drop rows whose predicted binder tier is below this threshold. 'strong'
                        keeps only strong; 'medium' keeps strong+medium; 'weak' drops only non-
                        binders. Requires --predictor.
  --min-references N    Drop rows backed by fewer than N distinct PMIDs. Default 1 (no filter).
                        Use 2+ to require independently re-observed peptides.
  --min-samples N       Drop rows backed by fewer than N distinct samples (donors / cell lines /
                        runs). Default 1 (no filter). A single PMID often contributes many samples
                        — --min-samples is usually a stronger evidence signal than --min-
                        references.
  --cell-type TYPE      Keep only observations from this cell type (the tissue/cell-type half of
                        IEDB's Cell Name, e.g. "Melanocyte", "B cell"). Case-insensitive; repeat
                        the flag to allow several types. Requires a corpus built with hitlist >=
                        1.30.57.
  --format {table,csv,json}
                        Output shape (default: table — protein > allele section headers with
                        peptide rows in an aligned table beneath each allele).
  --output OUTPUT, -o OUTPUT
                        Write to file (.csv / .json / .txt)
